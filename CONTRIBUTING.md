# Contributing

Contributions are welcome.

## Before submitting

- Read `SKILL.md` and the relevant references.
- Keep guidance practical and tool-neutral where possible.
- Avoid adding tool-specific assumptions to the main skill.
- Put tool-specific setup in `docs/AI-TOOLS.md`.
- Do not add secrets, credentials, private project data, or proprietary code.
- Explain the reason for significant changes.

## Documentation style

- Use clear Markdown.
- Prefer concise, actionable instructions.
- Include code examples only when they improve understanding.
- Mark illustrative snippets as examples.
- Do not claim a security technique is foolproof.
- Keep cross-references and repository structure up to date.

## Pull requests

Include:
1. Summary of the change.
2. Reason for the change.
3. Files affected.
4. Any compatibility or security implications.
5. Documentation updates.

## Security issues

Do not publish sensitive vulnerability details as an ordinary issue. Contact the repository maintainer privately using the contact method listed in the GitHub repository profile.
